# Goro App — GoroAI Client

The Flutter client for GoroAI, a multi-agent AI trading-intelligence platform. Ships as a web app today, built for mobile (Android/iOS) and desktop from the same codebase.

**Live:** https://app.zynost.com

## What it does

- Full authentication flow (signup, email verification, login, 2FA, password reset) against the GoroAI backend.
- Market screener, coin search, on-chain data, order-book radar, and watchlists.
- Displays AI-generated trade plans with the reasoning behind them (technical, on-chain, sentiment, macro, risk) and tracks their real outcomes over time.
- Portfolio tracking, alerts, notifications, and subscription/billing management (via Zynost Pay, non-custodial).
- Admin dashboard for operational oversight.

## Stack

Flutter (Dart) · single codebase targeting web, Android, iOS, desktop · deployed on Vercel (web)

## Status

In active production use by real users.
